# Network Academy

Proyecto académico realizado para la materia Introducción a la Programación Web.
El sitio presenta contenidos iniciales sobre redes informáticas mediante ejemplos
y explicaciones breves.

## Contenido

- Inicio y presentación del proyecto.
- Propósito y objetivos de Network Academy.
- Fundamentos de redes, diagrama de conexión, modelo OSI y protocolos.
- Herramientas básicas de diagnóstico de red.
- Información de contacto, formulario y acceso al repositorio.

## Estructura

```text
network-academy/
```

## Tecnologías utilizadas

- HTML5 para el contenido y la estructura semántica.
- CSS3 para los estilos, la navegación con Flexbox y la adaptación a pantallas pequeñas.

## Cómo visualizar el proyecto

Abrir el archivo `index.html` en un navegador web. No requiere instalación,
servidor ni dependencias externas.
